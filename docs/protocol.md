# Protocol architecture

IsaacMetalBridge is an unofficial experimental compatibility layer.
It is not affiliated with, endorsed by, sponsored by, or supported by Apple Inc. or NVIDIA Corporation.

The canonical v1 wire definition is [../protocol/README.md](../protocol/README.md) and the portable ABI header is [../protocol/include/imb_protocol.h](../protocol/include/imb_protocol.h).

The control plane contains version negotiation, discovery, error reporting, Ping/Pong, shutdown, resources, and fences. Protocol 1.13 includes real Metal resources, sparse residency, fixed raster/UI, translated compute, primitive/instance acceleration structures, bounded ray dispatch, and real command-buffer completion. Scene-state v13 carries visible USD Mesh geometry plus bounded material data. It retains v12's 156-byte fixed header and separate camera/static sequences, adds one globally deduplicated texture table, and uses 224-byte Mesh records that reference that table. The ICD accepts v3-v12 records and can still read only the header and reuse an existing TLAS during viewport navigation. `materialBind` GeomSubsets become disjoint Mesh face records. The 12 official Warehouse source-asset MDL modules are normalized into constant/base/roughness/metallic/emission/normal fields with their bounded mask, tint, desaturation, roughness-range, and normal-strength operations. Material flag bit 6 tags the official Barcode and WallBoard masks; `MBM1 v2` descriptor bit 5 and the instance texture-channel word carry that cutout state to Metal, where alpha below `0.3333` advances the ray and re-intersects up to 64 times. Scene textures accept sources up to 4096x4096 but downsample larger inputs to at most 512px per axis; geometry and images have separate 192 MiB and 128 MiB reservations, and no more than 126 unique images are published. Native proxies and bounded PointInstancer occurrences remain ordinary per-path Mesh records. Host execution is correctness-first by default: one primary ray per output pixel with secondary hard-shadow intersections at every TLAS size. `IMB_RAY_SHADOWS=adaptive IMB_RAY_PIXEL_STEP=adaptive` is an explicit performance opt-in that omits secondary shadow intersections above 256 instances and uses 2x2/4x4 primary-ray blocks above 256/512 instances. Arbitrary opacity/translucency, translated general RTX/Hydra shader semantics, nested instancing, robust deformation, soft shadows, unsupported FP64 modules, arbitrary Render Products, bulk queues, and zero-copy sharing remain future work.

The transport remains abstract. Local tests use child-process pipes. Production-path validation uses a Linux AF_VSOCK listener and a macOS adapter that calls Apple container's existing `ContainerClient.dial(id:port:)`; the complete session has passed in a real ARM64 VM. No dedicated VirtIO GPU or coherent shared memory is claimed.
